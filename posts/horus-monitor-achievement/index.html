HORUS Monitor - HMDを用いた自動運転車遠隔監視システムの開発

発表情報

発表者: 橋本 空輝（B3）
発表会: 第89回情報処理学会ユビキタスコンピューティングシステム研究発表会
演題: 「HORUS Monitor：ヘッドマウントディスプレイを用いた自動運転車遠隔監視システムの提案」
研究室: yumulab

プロジェクト概要

自動運転車（レベル4）の遠隔監視環境における操作性と作業快適性の課題に対応するため、ヘッドマウントディスプレイ（HMD）を活用した次世代遠隔監視システム「HORUS Monitor」 を開発しました。

物理的なディスプレイの固定配置に依存せず、XR技術を用いて仮想ディスプレイを実空間上の任意の位置に配置・カスタマイズできる革新的なシステムです。

背景：自動運転遠隔監視の課題

レベル4自動運転の実用化に向け、異常時や判断困難な場面に備えた遠隔地の人間オペレーターによる監視と介入支援が重要な役割を果たしています。

従来システムの問題点

  • 設備の移動が困難 - 複数台の物理ディスプレイをラックに固定するため、監視拠点が強く限定される
  • 個別最適化の難しさ - モニター配置、高さ、視距離などの細かい調整が困難で、個人の身体的特徴や好みに対応できない
  • 作業負荷の増加 - 複数画面の監視により視認効率が低下し、長時間利用では身体的負荷が増大

技術的アプローチ

システム構成

HORUS Monitorは以下の3要素で構成されています：

コンポーネント 役割 技術スタック
Receiver HMD上で映像受信・描画 Meta Quest 3, Unity, WebRTC
Sender 車載カメラ映像の送信 Web（HTML/JavaScript）
Signaling Server 接続管理 Node.js

主要機能

Receiver（Meta Quest 3アプリ）

  • WebRTC for Unityを用いた映像受信 - 複数ストリーム対応
  • バーチャルウィンドウの生成 - 各映像ごとに個別のUnityパネルを自動配置
  • 空間的位置管理 - HMD座標系で安定した仮想表示を実現
  • インタラクティブ操作 - コントローラやハンドジェスチャで位置・サイズを自由に調整

Sender（Webアプリ）

  • 解像度のカスタマイズ - ピクセル単位での柔軟な指定
  • 複数カメラ対応 - 1つのPeerConnection内で複数ストリーム同時送信
  • NAT越え対応 - STUNサーバ経由で通信を実現

評価と検証

実験設定

  • 被験者 - 大学生・大学院生9名
  • 被験者層 - 78%が未運転者、55.6%がHMD初心者
  • 比較対象 - ノートPC液晶ディスプレイ
  • タスク - 映像内のコンビニエンスストア数を数える監視タスク

定量評価結果（System Usability Scale）

評価対象 SUSスコア
平面ディスプレイ 80.25
HORUS Monitor 77.47

解釈： 総合スコアは平面ディスプレイがわずかに上回ったものの、使いやすさと機能統合性の項目ではHORUS Monitorが高い評価を獲得

ユーザーフィードバック

ポジティブ意見：

  • 「自由な大きさ・位置で見られるため見やすい」
  • 「手軽に配置設定できるのが魅力」
  • 個人の体格や作業スタイルに柔軟に対応可能

改善点：

  • HMD使用の慣れが必要（初心者向けの訓練が重要）
  • 長時間利用時の身体的負荷

技術的な成果

イノベーション

  1. HMDパススルー機能の活用 - 物理空間とデジタル情報のシームレスな融合
  2. WebRTC for Unity統合 - ブラウザとHMDアプリ間の安定した映像配信
  3. 空間的UI配置 - パーソナルスペース内での最適な情報提示レイアウト

実用化への道筋

  • 異なるユーザやタスクに応じた最適なUIレイアウト設計ガイドラインの確立
  • 長時間利用時の身体的負荷軽減策の開発
  • 複数オペレーター環境での協調監視システムへの拡張

今後の展開

  1. カスタマイズUI開発 - 監視員のプリファレンスに基づく自動レイアウト最適化
  2. マルチモーダル拡張 - 視覚情報に加えて聴覚・触覚フィードバックの統合
  3. 実運用環境での検証 - 永平寺町やトラック自動運転の実証環境への導入検討
  4. 持続可能性の向上 - VR酔いや目の疲労を軽減する技術の組み込み

成果と意義

HORUS Monitorは、自動運転の遠隔監視という極めて重要な業務に対し、HMD/XR技術を活用してオペレーターの作業環境を抜本的に改善する ことを実証しました。

従来のデスク拘束型の監視環境から解放され、柔軟で個人に最適化された監視空間の実現により、以下を期待できます：

  • オペレーターの疲労軽減と長時間監視の実現
  • 監視品質の向上と判断速度の加速
  • 複数拠点への迅速な展開

次世代の遠隔オペレーション技術として、自動運転やドローン、ロボティクス分野への横展開も視野に入れています。
